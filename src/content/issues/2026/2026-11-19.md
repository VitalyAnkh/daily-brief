虚宝早。昨夜的网络不太平：NGINX 爆出远程代码执行，一天前还是 Java4Shell。另一头，模型开始替人改写芯片的电路，也被人发现偷偷读过蛋白质数据库。今天就从这几件事读起。

## 爆文

**[Unauthenticated Remote Code Execution in NGINX](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities)** — Wiz Research，11月18日
两个 HTTP/2 漏洞（CVE-2026-123633、CVE-2026-123007），CVSS 4.0 评分都是 9.2，无需认证即可执行代码。其中整数下溢那一个从 2015 年的 NGINX 1.9.5 起就埋在代码里。Wiz、Rapid7 等五个团队各自独立发现了它们。文中说得直白：复杂曾是漏洞最好的掩护，AI 正在拆掉这道墙。你手上若有开着 HTTP/2 的服务器，先去打补丁。

**[Advancing chip design with OpenAI models](https://openai.com/index/advancing-chip-design-with-our-models/)** — OpenAI，11月18日
自研推理芯片 Jalapeño 上，模型提出的改动让向量单元的标准单元面积少了约 13%，矩阵单元少了约 10%，并已在硅片上验证。与 AMD 合作，旗舰 GPU IP 上最多提升 14%。后半篇的 RISC-V 评测更耐看：用 PicoRV32 和 Ibex 两颗开源核，比较模型「改旧设计」与「按规格从头设计」，共 9,881 次计分运行。从规格起步反而得分更高，作者也承认，这部分是因为模型可以省掉性能计数器之类的功能。

**[Claude was trained on protein sequences at scale](http://xinmingtu.cn/blog/2026/claude-opus-5-5-protein-sequences/)** — Xinming Tu
实验设计很干净：选 668 条几乎没人研究的细菌和古菌蛋白，让模型续写下一个氨基酸，再拿打乱顺序的同一条序列做对照。Fable 5.2 在真序列上猜中 54%，打乱后只有 9%；GPT、Gemini 和七个开源模型都接近零。11月18日的更新又加了 56 条八月才公开的新蛋白，结果依旧。这是从外部推断训练数据构成的范例，方法比结论更值得学。

**[Introducing Gemini 4 Neon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)** — Google，11月18日
定位是又快又够用的中档：Artificial Analysis 智能指数 61，排第三；每百万 token 输入 3 美元、输出 15 美元，上下文 100 万。连同前两天的 GPT‑6.2，各家的价格和能力曲线又挪了一格。拿来做编程代理的日常主力，值得一试。

**[We Need Smart People Who Give a Shit](https://violetpixel.com/blog/2026-11-17-we-need-smart-people-who-give-a-shit/)** — Justin Michael
作者在 Stripe 见识过 ACH 这类老系统，结论是：世界靠一群「懂行又在乎」的人用手撑着。把这些人当成本裁掉，系统就会悄无声息地塌下去。文章有情绪，却说中了这几周接连宕机背后那种说不清的不安。

## 深度

**[Energy-Based Reasoners: Your Recurrent Reasoner Should Be an Energy-Based Model](https://energy-based-reasoners.github.io/)**（[arXiv 2611.08977](https://arxiv.org/abs/2611.08977)）— Chen、Gladstone、Li、Ji、Du
循环推理模型的老毛病是不知道自己离答案还有多远，所以不知道什么时候该停。这篇让模型学一个能量函数：能量给当前状态打分，梯度指出往哪里改，梯度够小就停；多条轨迹各自求解，取能量最低的一条。1.8M 参数在 Sudoku‑Extreme 上做到 99.9%，推理算力比次优方法少 345 倍（HN 标题写成 385 倍，以原文为准）。读后所得：「验证器」不一定要外挂，可以长在模型自己的几何里，这是凸优化直觉在推理上的一次漂亮回归。

[The Magic of Partial Evaluation](https://jimmyhmiller.com/magic-of-partial-evaluation) — Jimmy Miller 从阶乘、幂函数一路讲到 Brainfuck 解释器：把程序里已知的部分在构建期算掉，只留下动态的残余。拿解释器加一段源码去做特化，得到的就是编译结果。文章不讲实用，只讲美，读完会明白 PyPy 和 GraalVM Truffle 为什么能成立。下面的书和人物都从这篇引出。

[Locating the source of a mysterious beep with Claude](https://simonwillison.net/2026/nov/9/mysterious-beeps/) — Simon Willison 屋里某个箱子隔一阵就叫一声。他让 Claude Code 把手边的手机、平板变成麦克风阵列：浏览器端用 FFT 加高通滤波检测蜂鸣，服务器让一台设备发一声 chirp 来对齐时钟，再按到达时间差三角定位，误差约 40 厘米。最后挖出一台缺电的一氧化碳报警器。方法源自 2007 年的 BeepBeep 论文。对学电子的你，这是一堂现成的声学测距课；对写代理的你，它说明一件事：让代理自己有感官，它才能自己迭代。

[The Fastest Soft Robot Ever Built Doesn't Need Electronics to Function](https://today.ucsd.edu/story/the-fastest-soft-robot-ever-built-doesnt-need-electronics-to-function) — UC San Diego；论文见 [Science Robotics](https://www.science.org/doi/10.1126/scirobotics.aei1264)，11月18日 六足软体机器人，一种材料，在桌面 FFF 打印机上一次打印成形，没有一块电子元件。腔室、阀门、管路全部打印在体内，用气压驱动，速度达 4.72 米/秒，比 2022 年的初代快了一百多倍。关键一招借自复式蒸汽机：高压气先在小腔里驱动阀门，再进大腔推腿，把余压吃干净。打印不只是造外壳，也能直接打出逻辑与动力，这对你的 3D 打印学习是一道新的边界。

[A Primer on Fourier Series](https://arxiv.org/abs/2510.18203) — Dipierro、Pfefferlé、Valdinoci 去年十月放上 arXiv 的一整本教科书，昨天在 HN 上重新浮起。本科、研究生都能用，习题附完整解答，免费。上面的蜂鸣检测靠 FFT，示波器上的每一条频谱也离不开它。趁这阵学电子，把收敛性这些地方补扎实，正是时候。

## 书

《Partial Evaluation and Automatic Program Generation》，Neil D. Jones、Carsten K. Gomard、Peter Sestoft 著，Prentice Hall International，1993（ISBN 0-13-020249-5）；作者在 [ITU 官网免费提供全文](https://raspi.itu.dk/people/sestoft/pebook/pebook.html) 部分求值领域的奠基教科书，从自应用的特化器一路写到「编译器生成器」，二村投影在这里第一次被系统地实现。读完 Miller 那篇意犹未尽，就该接上这本。你写 Rust、看 e‑graph 和编译器，这本书给的是更底层的一层视角：编译只是求值的一种特殊情形。

《Digital Design and Computer Architecture: RISC-V Edition》，Sarah L. Harris、David Harris 著，Morgan Kaufmann / Elsevier，2021（ISBN 978-0128200643）；[作者主页](https://pages.hmc.edu/harris/ddca/ddcarv.html) 从数字逻辑一路写到亲手搭一颗 RISC-V 处理器，配 SystemVerilog 示例和实验。OpenAI 那篇里模型改的就是 SystemVerilog RTL，测的就是 RISC-V 核。想自己判断「模型像资深微架构师」这句话有几分成色，最好先能读懂它改了什么。比上期的 Nand2Tetris 更贴近真实的芯片设计。

## 人物：二村良彦（Yoshihiko Futamura）

1942 年生，1965 年在北海道大学读完数学，进日立中央研究所，1991 年转任早稻田大学教授，直到 2005 年（[个人主页](https://fi.ftmr.info)）。1971 年，他用日文发表《Partial Evaluation of Computation Process — An approach to a Compiler-Compiler》，提出后来以他命名的三个投影：拿解释器对源程序做特化，得到目标程序；拿特化器对解释器做特化，得到编译器；拿特化器对自身做特化，得到编译器生成器。英文版直到 1983 年才发表（[概述见维基](https://en.wikipedia.org/wiki/Partial_evaluation#Futamura_projections)）。半个世纪后，PyPy 的 RPython 和 GraalVM 的 Truffle 都是第一投影的落地。他还发明了 PAD 问题分析图，后来成了 ISO 8631 和中国国家标准 GB 13502。

可借鉴处：一个在企业研究所做工程的人，把「编译器从哪里来」这种看似哲学的问题，写成了可以计算的等式。他主页标题上还开了个玩笑，YF = F(YF)，一个不动点。理论的好坏不看出身，看能否自我应用。

## 反面观点

主流共识：AI 正在批量挖出 C/C++ 和手写汇编里的陈年内存漏洞（NGINX、PHP、Java4Shell），所以出路是把基础设施改写成 Rust 这类无 GC 的内存安全语言。

**Ethan McCue，[《Java4Shell is a reason to use Java》](https://mccue.dev/pages/11-18-26-java4shell)**
他偏偏借 Java4Shell 为 Java 辩护，论证有三层。一，这次的漏洞出在 JVM 一段手写的汇编内建函数里，属于一个集中、可以重点审计的依赖，普通 Java 代码本身是内存安全的。二，Java 对原生代码有门禁：库要调原生代码，使用者必须显式加 `--enable-native-access`，整棵依赖树里有多少原生暴露面，一目了然；C#、Python、JS、Go 都允许任意依赖悄悄带进原生代码。三，JIT 让 Java 快到多数人用不着原生扩展，他用《一周末光线追踪》实测，带值类型的 Java 28 耗时约是 C++ 的 1.71 倍。

我的掂量：第二点最有分量。AI 让找漏洞变便宜之后，真正稀缺的是「我到底暴露了多少原生代码」这张清单，Java 的模块门禁确实给出了一种可审计的答案。但他回避了一点：JVM 自己就是最大的原生暴露面，Java4Shell 恰好落在 AVX‑512 这种最难审的角落；性能数据也只有一个基准。结论不必是 Java 胜过 Rust，更稳的说法是：语言层面的内存安全只是必要条件，能把不安全的部分收拢、圈定、计数，同样要紧。

## 公众号选题

**题目：《模型开始改写电路：AI 设计芯片这件事，到底走到了哪一步》**

切入角度：不追「AI 取代芯片工程师」的热闹，只问一个工程问题：模型的改动凭什么可信？答案藏在验证链条里，也就是 Synopsys 的等价性检查、仿真和 Yosys 估频。模型只负责提出改动，判官另有其人。

大致结构：
1. 引子：Jalapeño 的乘法器面积少了 15%，延迟从两拍降到一拍，这在 RTL 层面意味着什么。
2. 实证：AMD 最多 14% 的 PPA 提升，「一年进度五个月做完」这类说法应该怎么读。
3. 实验：PicoRV32 和 Ibex 两组评测里，为什么「按规格从头设计」比「改旧设计」得分更高；作者自己也指出了漏洞，比如可以省掉功能，也没有做物理综合后的时序检查。
4. 对照：同一周，Wiz 用模型挖出 NGINX 沉睡十年的漏洞。生成与验证、攻与守，其实是同一种能力的两面。
5. 收束：给想入门的读者一条路，从 Harris 的 RISC-V 教材起步，再到 Yosys 和开源核。

可用素材：[OpenAI 原文](https://openai.com/index/advancing-chip-design-with-our-models/)、[Wiz 的 NGINX 披露](https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities)、[Harris《DDCA RISC-V》](https://pages.hmc.edu/harris/ddca/ddcarv.html)，再加二村投影作为「机器生成机器」的思想前史，点到即可。
