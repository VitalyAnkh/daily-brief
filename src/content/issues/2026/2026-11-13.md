虚宝：

今天是十一月十三日。近几日读过、也核对过原文的一些文字，记在下面。

## 爆文

Sparks of Weight-Space Programming: LLMs can natively read & write neural network weights Rikiya Takehi、Jayden Teoh、Alex Zhang、Omar Khattab，麻省理工学院计算机科学与人工智能实验室，十一月二日。本月在黑客新闻上传得很开。文中称，GPT-6 Astra 不经梯度下降，只改动 Qwen3.5-0.8B 中百分之零点零一六的权重，便将 MATH-500 从百分之七点九提高到百分之四十八点一。作者把这种做法叫做“权重空间编程”：把权重当作可读可写的程序。宜与后面的异见对读，不宜只看摘要。

\*sshole Ozgun Kultekin 撰写。OpenSSH 跑在 musl（Alpine、OpenWrt、Buildroot、Yocto，以及许多容器镜像）且未启用 PAM 时，影子文件里密码栏仅为星号的账户，会被超过二百五十六字节的任意口令放行。线索从一九八〇年 Unix 用星号锁定账户，接到二〇一二年 musl 的一处返回值选择，再接到二〇一六年 OpenSSH 为防计时泄漏而“借用别人盐值”的修补。正式修复见于 OpenSSH 10.6p2。用容器或嵌入式系统的人应当看一看，并尽快升级。

Introducing AlphaProof Code Google DeepMind，十一月十日。多智能体框架与研究者合作，把 Signal 密码协议的安全目标写成形式化规约，再生成六百余万行经 Lean 核验的证明，四周完成过去往往要专家团队数年的工作。这是首次在编译后代码的层面验证一套广泛部署的密码协议的关键安全性质。形式化证明不再只停在设计稿上。

The PHP2Shell Vulnerability Heralds Cybersecurity Hell Dina Genkina 写于《IEEE Spectrum》，十一月二日，副题即网上流传的那句：人工智能正在逼我们偿还四十年的技术债。PHP 里一处二〇二四年就报过、本只会造成崩溃的内存错误，在人工智能辅助下被做成了可执行任意代码的漏洞。发现用了约两周，补丁却要四名工程师做两个月。Matthew Green 只劝一句：有安全更新，不要拖到下周。

Top Chinese Frontier AI Models Carry the Fingerprint of Export-Controlled NVIDIA Blackwell GPUs Will DePue，十一月十二日。作者从公开权重里找回初始化痕迹，指出 DeepSeek、Moonshot AI、MiniMax、蚂蚁集团自四月以来的六款模型，其起始排布与 Blackwell 的流处理器布局相符，较早的模型则仍像 Hopper。文章写得克制：指纹证明的是生成起始权重的硬件，不能单独证明训练地点，也不能单独构成违规。宜读原文，不宜只看标题。

## 深读

StateBench 艾伦人工智能研究所，十一月三日。把“状态追踪”分成四等，背后是克罗恩—罗德斯理论对有限状态问题的分层。前沿模型在易的层级尚可，一到“一般有限”问题、输入再拉长，准确率降到百分之十三或更低。专门训练时，Gated DeltaNet 与混合架构能外推到远超训练长度，Transformer 则始终学不会最难的一档。读长文、跟代码、盯住对话里不断改写的对象，难处其实是同一种。

TCSExam: Evaluating Frontier LLMs on the Full Range of TCS Research 骆逸凡、刘正瀛、袁洋、杨植麟、姚期智。一百道专家审定的题，覆盖定理证明、求解器工程、数学构造与开放猜想，提交由 Lean 内核或可执行检查器核验。GPT-6 Astra 在研究级定理上单次完全证明率达百分之七十；开放猜想几乎仍未解决，个别“得手”其实是检索到了已公布的反例。真正有分量的，是那些未能结案、却可独立核验的边角结果，例如把 $\mathbb{F}_5$ 上的 Alon–Jaeger–Tarsi 猜想推到九维。人工智能能做研究里可检验的一段，还远不能替数学家把猜想关掉。

Using voltage glitching to unleash the A100 in my mining card Kate，十一月十日。她在 GA100 上找到电压故障注入路径，让一张名义八吉字节的 CMP 170HX 矿卡在功能上接近 A100-80G，显存、流处理器、PCIe 4 与 NVLink 均可打开，FP16 吞吐约为零售 A100 的一点一八倍。要害在设计：英伟达用熔丝分档，有些限制竟可再烧熔丝放宽。正在学电子学的人，可以从这里看见“同一块硅，不同货架”的真实机关。

First structure 3D-printed in the extremes of open space 欧洲航天局，十一月十一日。Orbital Matter 的 Replicator 2 卫星在开放空间用光敏树脂，三十分钟打出一根长三十二点五厘米的空心臂杆，并借它顶开太阳能帆板。真空逸气、冷热交替、微重力，都被顶了过去；树脂在轨存放三个月，打印面仍均匀。对学三维打印的人，这不是展览新闻，而是工艺在最苛刻边界上的一次实测。

AI usage generates a fragile codebase Evan X. Merz，十一月七日。他在大公司里代码已百分之百由人工智能生成，因为评级需要。他列了四种脆弱：测试浮浅、代码过繁、人对系统的理解变薄、评审追不上合并；随之是事故变多、恢复变慢、错误只在真实用户那里显现。说法来自现场，不是宣言；对照自己的仓库读即可，不必先接受他的全部结论。

## 书两本

Six Math Essentials，陶哲轩著，Quanta Books，十一月十日上市，精装一百二十八页。他写给普通读者的第一本书，六个入口：数、代数、几何、概率、分析、动力学。西蒙斯基金会的介绍里 Ben Orlin 说，读它像是从梅西的眼睛里看足球。你已有编程与数学的底子，这本短书适合用来重新对齐直觉，而不是当教材。

Big Math: The Hidden Codes That Run Our World，Steven Strogatz 与 Alex Townsend 著，Little, Brown，同日出版。他们把必须借助计算机才能计算、甚至才能理解的数学称作 Big Math，它在手机、贷款审批、核磁扫描与推荐算法里默默运作。康奈尔的报道引 Townsend 的话：我们讲得清人工智能的机械结构，却还解释不了那些数字何以恰好做成这件事。陶哲轩给的是六种思想的骨架，这两位给的是这些思想被计算机放大后的世界，正好并读。

## 人物

Tim Peters（1952–2026）。十一月十一日，Guido van Rossum 在 Python 论坛的悼文里宣布他已于七月十五日去世。他写下《Python 之禅》，二〇〇二年设计了 Timsort，后被 Java 与 Android 采用。他曾在 Cray 写超级计算机编译器，在 Dragon Systems 做当年几乎被认为不可能的语音识别；字典、循环垃圾回收、生成器、浮点与长整数，都有他打磨的痕迹。可借鉴的不只是算法，而是把严格、常识与幽默写进技术说明的那种态度。他最后一次论坛发言收在这句话里：真实世界，总比我们干净的抽象所希望的更复杂。

## 反面意见

主流说法是：前沿模型已能像读代码一样读写神经网络权重。Matthew Honnibal 在 The 'Astra can read and write weights to improve Qwen' post is misleading 里并不否认实验，而是指出叙述把不同手法收进了同一句摘要：“只看原始权重”只出现在十几万参数、且不运行网络的小实验里；成为标题的 Qwen 实验，则用了 Python，并允许最多五十次前向传播。原作者十一月十二日补了回应，说这是一种正在出现的能力，而非方法论文。这个澄清有必要，但 Honnibal 的对照仍然成立。原实验也诚实记下了另一面：在很少陷入循环的 Gemma 3 270M 上，同样的编辑几乎加不进新的数学能力。异见的价值，正在于把“去掉故障模式”和“凭空写入能力”分开。

## 一个选题

**题目：** 《模型直接改权重：新能力，还是戏法？》

从那条流传极广的摘要写起，再把实验条件一一摊开，面向用过智能体、也关心模型内部机制的技术读者，语气冷静，少作判决。结构可分五段：爆文许诺了什么、数字从何而来；用 Honnibal 的对照表区分“直读权重”与“在 Python 里分析并运行后再改”；原作者的回应；判断的界限，即切除循环之类的故障并不等于添上本没有的能力，Gemma 实验是证据；最后留给程序员一个问题清单，以后再见到“直接改权重”，先问工具、前向次数、对照是否换过模型。素材有 Takehi 等人的原文与补记、Honnibal 原文、公开的实验日志仓库，以及 Hugging Face 上据日志重建的改后权重。把已发表的条件写清楚，这篇就站得住。
